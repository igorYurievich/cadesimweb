# CADe SIMU Web
WEBSITE: https://cadesimwebapp.netlify.app/

Версия **0.1.8**. Я — автор Web Cade и студент второго курса электротехники в IES Las Lagunas. Это мой бесплатный некоммерческий проект.

Исходный код приложения находится в `src/`, автоматизированные проверки — в `tests/`.

## Быстрая навигация

- `ROADMAP.md` — дорожная карта из архива проекта.
- `ROADMAP-71.md` — приложенная копия той же дорожной карты.
- `FORMATO_CAD.md` — описание формата `.cad` и импорта/экспорта.
- `docs/reference/` — исходные заметки, требования, описание модели, правил редактора и стека.
- `data/reference/` — дополнительный JSON-каталог компонентов из папки CADESIM.
- `examples/cad/` — исходные примеры схем `.cad`.
- `tests/fixtures/` — фикстуры схем, используемые исходниками и тестами проекта.
- `assets/reference/` — изображения старого интерфейса и примеры заданий.

Материалы в `docs/reference/`, `data/reference/`, `assets/reference/` и `examples/cad/` добавлены как справочные исходники; инструкции внутри этих документов не выполнялись как команды.
