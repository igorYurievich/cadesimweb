# Правила редактора схем (предложение)

Это мой проект логики редактора, а не описание оригинала. Пометки:

- **[оригинал]** — подтверждено данными из exe или открытых источников.
- **[предл.]** — моё предложение, его нужно сверить с оригиналом и поправить.

Область: режим «символ» (без 2D/3D, GRAFCET, ПЛК и совместимости с `.cad`).

---

## 1. Основные понятия

| Понятие | Определение |
|---|---|
| Лист | Рабочая область с размером (A4/A3/своё), рамкой, штампом и сеткой |
| Элемент | Размещённый символ: тип, позиция, поворот, зеркало, имя, функция, параметры |
| Клемма | Точка подключения элемента: номер/метка, положение относительно элемента |
| Провод | Ломаная из ортогональных отрезков между двумя точками подключения |
| Узел | Точка, где соединяются три и более отрезков проводов или клемм |
| Сеть | Множество клемм, соединённых проводами (электрически один потенциал) |
| Режим | Редактирование, симуляция, пауза, пошагово |

## 2. Координаты и сетка

- **[предл.]** Все координаты в единицах сетки. Шаг сетки по умолчанию 10 пикселей при масштабе 100 %. Положение элемента и клемм всегда кратно шагу.
- **[оригинал]** Сетка включается и выключается (меню «Rejilla»).
- **[предл.]** Привязка к сетке включена по умолчанию, временно отключается удержанием Alt.
- **[предл.]** Масштаб 10–800 %, колесо мыши масштабирует относительно курсора, средняя кнопка или пробел+перетаскивание двигают лист.
- **[оригинал]** Команды масштаба: предыдущий, 100 %, увеличить, уменьшить, по окну, весь лист.

## 3. Режимы

| Режим | Что можно делать |
|---|---|
| Редактирование **[оригинал]** | Размещать, перемещать, соединять, менять свойства |
| Симуляция **[оригинал]** | Нажимать кнопки и переключатели, смотреть состояние. Редактирование запрещено |
| Пауза **[оригинал]** | Остановить время (таймеры), сохранить состояние. Взаимодействие можно продолжить |
| Пошагово **[оригинал]** | Продвигать симуляцию по одному шагу вычисления |

Правила переходов:

1. Редактирование → Симуляция: схема проверяется (раздел 11), при критических ошибках запуск блокируется с сообщением.
2. Симуляция → Редактирование: состояния всех элементов и таймеров сбрасываются в исходные.
3. В режиме симуляции выбор, перемещение и удаление недоступны.

## 4. Размещение элементов

1. Пользователь выбирает тип в палитре. Курсор показывает «призрак» символа.
2. Клик по листу ставит элемент в ближайшую точку сетки. Клик продолжает размещение второго экземпляра (режим повторения). Esc или правая кнопка завершают.
3. Перед кликом можно повернуть призрак клавишей R и отзеркалить клавишей F **[оригинал: есть команды поворота и зеркала]**.
4. **Имя по умолчанию [оригинал: у каждого нового элемента есть имя и номера клемм по умолчанию]:**
   - **[предл.]** префикс по типу (по IEC 81346): `KM` контактор, `K` реле, `S` кнопка, `F` предохранитель и защита, `Q` автомат, `M` мотор, `H` лампа, `KT` таймер, `B` датчик, `X` клемма.
   - **[предл.]** следующий свободный номер: `KM1`, `KM2`, …
5. **Контакты и кнопки, управляемые катушкой,** создаются с пустым именем и подсвечиваются предупреждением, пока имя не задано (раздел 8).
6. Элемент нельзя поставить так, чтобы его клемма совпала с чужой клеммой, не будучи соединённой. Такая ситуация считается ошибкой размещения: **[предл.]** клеммы автоматически соединяются, если совпали в одной точке (опция «Conexiones automática» **[оригинал: есть такая опция]**).

## 5. Выделение, перемещение, удаление

- Клик выбирает элемент или отрезок провода. Shift добавляет к выбору. Рамка выделяет всё, что попало целиком.
- **[оригинал]** Есть «Seleccionar todo» (Ctrl+A в программе используется для «Abrir», поэтому в новой версии: Ctrl+A выбрать всё).
- Перемещение: перетаскивание мышью или стрелки (на шаг сетки; Shift+стрелки на 10 шагов).
- **[предл.]** При перемещении элемента подключённые к его клеммам провода растягиваются, сохраняя ортогональность. Провода, не касающиеся клемм, остаются на месте.
- Delete удаляет выбранное. При удалении элемента его провода остаются, но свободные концы подсвечиваются.
- Поворот влево/вправо на 90° и зеркало по горизонтали/вертикали **[оригинал]** применяются к выбранной группе вокруг её центра.

## 6. Провода

### 6.1 Создание

1. **[предл.]** Провод начинается кликом по клемме (курсор в виде перекрестия при наведении) или по существующему проводу (создаётся узел).
2. Курсор тянет ортогональную ломаную: по умолчанию Г-образный маршрут (сначала горизонталь, потом вертикаль). Клавиша Пробел переключает вариант (сначала вертикаль). Клик в пустом месте фиксирует излом и продолжает провод.
3. Завершение: клик по клемме, по проводу (создаёт узел) или двойной клик в пустом месте (свободный конец, допустимо, но даёт предупреждение).
4. Esc отменяет текущий провод.

### 6.2 Правила геометрии

- Отрезки только горизонтальные и вертикальные.
- Соседние коллинеарные отрезки склеиваются автоматически.
- Провод не должен идти сквозь клемму другого элемента без соединения: при попытке провод привязывается к клемме.

### 6.3 Пересечения и узлы

- Два провода, пересекающиеся без узла, **не соединены** (рисуются «мостом» или просто пересекаются).
- Узел появляется только в трёх случаях: провод заканчивается на другом проводе, пользователь явно ставит точку, либо две клеммы совпали в одной точке.
- Узел рисуется заполненной точкой.

### 6.4 Цвета, толщина и тип

- **[оригинал]** Цвета проводов выбираются из палитры (в программе есть кабели Fase, Neutro, Protección, Positivo, Negativo, цветной, толщина 1–4).
- **[оригинал]** «Cable III» (трёхжильный) и «Manguera» (шланг) как отдельные типы. **[предл.]** Трёхжильный кабель реализовать как три параллельных провода одним объектом.
- **[оригинал]** Опция «Visualizar número de cable»: показывать номер/метку провода на схеме.

### 6.5 Редактирование

- Перетаскивание отрезка двигает его перпендикулярно направлению, соседние отрезки растягиваются.
- Двойной клик по проводу: свойства (цвет, толщина, метка).
- Удаление отрезка удаляет весь провод между узлами/клеммами.

## 7. Свойства элемента

Диалог или боковая панель. Общие поля **[оригинал]**:

- **Nombre** (имя),
- **Función** (описание),
- **Conexión 1…N** (метки клемм),
- **Visualizar** (показывать ли текст на схеме).

Правила:

1. Изменения применяются сразу, отмена — Ctrl+Z.
2. Имя допускает буквы, цифры, дефис и подчёркивание. Пробелы запрещены **[предл.]**. Регистр различается.
3. Метки клемм **[предл.]** по умолчанию берутся из стандарта (A1/A2 катушка, 13/14 замыкающий контакт, 21/22 размыкающий, 95/96 и 97/98 тепловое реле, 1/2, 3/4, 5/6 силовые контакты). Пользователь может изменить.
4. Параметры специфичны для типа (таймер: шкала времени и выдержка; лампа: цвет; датчик: 2/3 провода, PNP/NPN; и так далее, см. таблицу параметров в данных из exe).

## 8. Имена и связь по имени

**[оригинал]** Элементы с одинаковым именем срабатывают вместе: состояние катушки с именем X определяет состояние всех контактов с именем X. Если имя у контакта не совпало ни с одной катушкой, он не работает.

Правила, которые я предлагаю:

1. **Источник состояния** — катушка, таймер, реле, мотор-контактор и др. «управляющий» элемент. **Исполнитель** — контакт, вспомогательный контакт, контакт таймера и подобные.
2. **Несколько исполнителей с одним именем** допустимы и ожидаемы (контакт NA и NC одной катушки).
3. **Несколько источников с одним именем**:
   - **[предл.]** запрещено, красное предупреждение при проверке. Оригинал это допускает или нет — выяснить опытом (план проверки, опыт 2).
4. **Исполнитель без источника**: жёлтое предупреждение «нет катушки с именем X», в симуляции остаётся в исходном положении.
5. **Переименование** источника по умолчанию спрашивает: «переименовать и все связанные контакты?» **[предл.]**
6. **Подсветка связи**: при выборе источника подсвечиваются все его исполнители на листе, и наоборот **[предл.]**

## 9. Взаимодействие в режиме симуляции

| Элемент | Поведение |
|---|---|
| Кнопка без фиксации **[оригинал]** | Пока зажата левая кнопка мыши, включена; при отпускании возвращается |
| Кнопка с фиксацией, переключатель, селектор | Клик переключает положение; положение сохраняется |
| Гриб (аварийная кнопка) | Клик фиксирует нажатие; повторный клик (или Shift+клик) возвращает **[предл.]** |
| Концевик, датчик | Клик (или клик с удержанием) имитирует срабатывание; тип как у кнопки задаётся параметром **[предл.]** |
| Автомат, рубильник | Клик переключает |
| Тепловое реле | Кнопка «Reset» в контекстном меню; симулятор срабатывания перегрузки через контекстное меню «Имитировать перегрузку» **[предл.]** |

Цвета **[оригинал: провода под напряжением ярче]**: провод под напряжением — яркий, без напряжения — тусклый. **[предл.]** цвет самого напряжения зависит от потенциала (фаза L1/L2/L3 разными оттенками).

## 10. Копирование, вставка, отмена

- Ctrl+C / Ctrl+X / Ctrl+V **[оригинал: есть]**. Вставка со смещением на шаг сетки. Провода, оба конца которых входят в выбор, копируются; одиночные не копируются.
- **Имена при вставке [предл.]**: если копия создала бы дубль источника, имя увеличивается на единицу (`KM1` → `KM2`). Исполнители не переименовываются автоматически, но их список предупреждений обновляется.
- Между окнами (несколько схем открыто одновременно **[оригинал]**) копирование работает так же.
- Undo/Redo **[оригинал: есть]**: каждая законченная команда одним шагом (размещение, перемещение группы, изменение свойств, создание провода). Глубина не ограничена **[предл.]**. История сбрасывается при загрузке файла, не при смене режима.

## 11. Проверка схемы перед симуляцией

Критические ошибки (запуск запрещён):

- два и более источника с одним именем (если опыт покажет, что оригинал это запрещает);
- замкнутый короткий путь между источниками разных потенциалов без нагрузки.

Предупреждения (запуск разрешён):

- исполнитель без источника;
- источник без исполнителей;
- свободный конец провода;
- клемма без соединения у элемента, где она обязательна;
- два провода с общей точкой без узла (визуально похоже на соединение).

Результаты показываются списком; клик по записи выбирает и центрирует элемент.

## 12. Лист, рамка, штамп, печать

**[оригинал]** Параметры листа: A4 (верт./гор.), A3 (форматы 1 и 2), своё; рамка «Contorno» и разметка «Referencias»; штамп 1/2 или без; цветная печать; смещение X/Y 0–100; масштаб 0,1–5; толщина линии печати 1–5.

**[оригинал]** Поля штампа: Entidad, Título, Fecha, Número, De, Archivo, Dibujado, Comprobado, Nombre, Fecha; выравнивание Izq/Cen/Der.

**[предл.]** Печать и экспорт: SVG и PDF; в PDF сохраняются слои (провода, элементы, текст). В режиме симуляции печатается текущее состояние (цвета под напряжением), если включена опция.

## 13. Рисование и текст

**[оригинал]** Есть линия, прямоугольник, эллипс, залитые прямоугольник и эллипс, заливка, цвет (13 цветов), толщина 1–4, текст (шрифт, ориентация), числа. Они не участвуют в электрической модели.

## 15. Что проверить опытами в оригинале

1. Можно ли поставить два источника с одним именем и что произойдёт.
2. Как ведёт себя клемма, если провод проходит через неё без остановки.
3. Нужен ли явный узел при пересечении проводов (в оригинале провода могут соединяться при касании?).
4. Что именно делает «Conexiones automática de cables».
5. Нужно ли в оригинале переименовывать контакты руками или есть автосвязь.
6. Размер шага сетки и допустимые углы проводов.
7. Как в оригинале обозначается нажатая кнопка с фиксацией и как её отпустить.
